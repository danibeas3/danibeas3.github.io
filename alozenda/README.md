# Alozenda · web comercial

Landing estática independiente de la aplicación y de Arto Blanco. Cloudflare Pages publica la carpeta `alozenda` del repositorio `danibeas3/danibeas3.github.io`, rama `main`, sin compilación y con directorio de salida `.`.

- Proyecto Pages: `alozenda-daniruiz`.
- Dominio: `https://alozenda.daniruiz.com/`.
- Demo funcional: `https://alozenda-demo.dani-ruizporcel.workers.dev/`.
- Formulario: Worker compartido documentado en `../services/portaldoc-contact/README.md`.

El portfolio personal utiliza `imagenes/portfolio/alozenda-logo.svg` y enlaza a esta landing. Las vistas de `preview/` son copias estáticas de la interfaz con datos ficticios; la aplicación interactiva se abre desde los enlaces de demostración.

Para una vista previa local, ejecutar el servidor de desarrollo del repositorio y abrir `/alozenda/`. El envío se habilita únicamente en el dominio público, con Turnstile y validación del servidor. No añadir secretos a esta carpeta.
